# 디지털 소외계층 웹 탐색 지원 서비스 프론트엔드

React + TypeScript + Tailwind CSS + Zustand 기반 프론트엔드 프로젝트입니다.

## 실행

```bash
npm install
npm run dev
```

## 테스트 (TDD)

```bash
npm run test
npm run test:watch
npm run test:coverage
```

- TDD 작업 가이드는 TDD_GUIDE.md를 참고하세요.

## 기능 모듈

- F-1 Dashboard
- F-2 StreamViewer
- F-3 SmartOverlay
- F-4 VoiceController
- F-5 MainController
